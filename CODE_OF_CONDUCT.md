# Code of conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and assume good faith. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks, or publishing others' private information.
- Keep feedback specific and actionable; keep reviews kind.

Maintainers may edit or remove comments, commits, issues and pull requests that violate this code, and may
temporarily or permanently ban contributors for behaviour they judge inappropriate.

To report a problem, open a private security advisory on this repository or contact the maintainer through
their GitHub profile ([@Nithinfgs](https://github.com/Nithinfgs)).
